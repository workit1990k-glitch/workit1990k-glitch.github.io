Single-file starter

Manga downloader

Paste a chapter link and download its pages as a ZIP. This standalone HTML page can work directly only with image URLs the browser is allowed to access; most manga sites require a site-specific API or a small local server.

Ready. Paste a chapter URL.

Important: a URL alone does not reveal every page image. This single-file version supports direct image URLs and simple chapter pages whose image elements are accessible to the browser. It cannot bypass CORS, logins, paywalls, or site protections. XComic's GraphQL chapter API generally needs a server-side request, so the previous XComic-specific downloader requires Node.js.

For best results, paste a direct image URL to download one image, or use a chapter page that exposes readable image links. Only save content you are authorized to download.
